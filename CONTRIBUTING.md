# Contributing to Google Photos Backup (gpb)

First off, thank you for considering contributing to `gpb`! People like you make this tool better for everyone.

We welcome any kind of feedback, whether it's bug reports, feature requests, or Pull Requests.

## 💬 Community and Feedback
Are you using this tool? We'd love to hear from you! Please consider [opening an issue](https://github.com/othermore/google-photos-backup/issues/new/choose) just to say "Hi, I'm using this!" and let us know how it's working for you. Your feedback is what keeps this project alive and motivated.

## 🐛 Bug Reports
Bugs are tracked as [GitHub issues](https://github.com/othermore/google-photos-backup/issues). When you create a bug report, please include as much detail as possible:
* Your Operating System and Architecture
* The version of `gpb` you are using
* Steps to reproduce the issue
* What you expected to happen vs what actually happened

## 💡 Feature Requests
Feature requests are also tracked as [GitHub issues](https://github.com/othermore/google-photos-backup/issues). When creating a feature request:
* Describe the problem you are trying to solve.
* Explain how the new feature would solve it.
* Suggest potential alternatives if applicable.

## 🛠 Pull Requests
We gladly accept Pull Requests! To ensure a smooth process:
1. **Discuss first (Recommended)**: If you plan on making a large change, please open an issue first to discuss it. This ensures your time isn't wasted on something that might not align with the project's goals.
2. **Fork the repo** and create your branch from `main`.
3. **Format your code**: Run `go fmt ./...` before committing.
4. **Lint your code**: Ensure `golangci-lint` passes without warnings.
5. **Describe your changes**: Write a clear PR description detailing what you changed and why.

Thank you for contributing!
